# Hi, I'm Sam

Technical Product Manager at [Shopware](https://www.shopware.com), where I lead [Shopware Nexus](https://nexus.shopware.com), our event-driven integration platform. I took Nexus from closed beta to a commercial launch this year and I'm now taking it to general availability.

Before product I spent a decade building cloud infrastructure: Principal Cloud Engineer at Shopware, DevSecOps across UK public sector programmes, and infrastructure engineering at the Ministry of Defence. I still write code when it's the fastest way to answer a question; the first Nexus ERP connector proof-of-concept and its adoption dashboards started as my commits.
